The data engine now caches one spatial merge per country/origin/radius/filter query and evaluates only the requested 160-station page. All matching station identifiers and coordinates remain in a lightweight map inventory independent of the current page. The map groups only markers in its viewport on a grid whose cell size changes with zoom; evaluated calculable offers on the current page take visual priority within a group. Other stations remain reachable by page navigation or map selection, which opens their page. Raw offers remain distinct from calculable results and are never promoted by the map.
