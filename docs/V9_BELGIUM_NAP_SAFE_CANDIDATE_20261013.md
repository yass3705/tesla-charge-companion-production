# Belgium NAP: safe V9 development candidate

The pinned [Eco-Movement Belgium NAP selected-CPO feed](https://transportdata.be/en/dataset/public-charging-infrastructure-dynamic-dataset-selected-cpos-datex-ii) is a public charging source with ad-hoc prices. Data Lab commit `047e1911a5dfd4dcce741ad9b461c6096effb9cd` preserves 17 source pages and their manifest. Membership in this selected-CPO source is the project's public-access basis; it does not prove national coverage beyond the included operators.

The previous V9 Belgium adapter treated every `pricePerMinute` and `flatRate` record as an energy price and emitted values marked `taxIncluded: false` without VAT. That could create false ranked costs, so the new adapter accepts only an EVSE with exactly one `adHoc` `pricePerKWh` record in EUR, `taxIncluded: false`, explicit `taxRate: 21`, a rate ID and a finite amount. It converts that amount to gross EUR with 21% VAT. An EVSE with any additional component, another rate form, unknown VAT or unsupported currency keeps its supported connector inventory but has no numeric offer. The connector types retained are Type 2, CCS Combo 2 and domestic E. No minute or fixed fee is guessed or counted twice.

The pinned source audit gives **16,961 sites, 70,043 supported EVSEs, 41,706 safe energy-only offers and 28,337 supported EVSEs without a ranked amount**. Another 480 raw EVSEs have no supported connector. These counts are guarded by a test against the actual 17 pages, alongside a Brussels runtime query and the nine-country smoke. Offers use the source EVSE identity and connector power; no station average is created.

`2026-10-13-nine-country-be-candidate` adds this dataset as the ninth non-Tesla country in development, while preserving the previous immutable candidate for rollback. The Data Lab subscription evidence from PR #203 is pinned as source context only; its discount percentages still cannot create EVSE-specific eMSP amounts. This is not a Pages or Cloudflare deployment.
